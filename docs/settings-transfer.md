# 系统设置导入与导出

`/admin/settings` 顶部提供“导出设置”和“导入设置”。先保存当前页未提交的修改，再操作。导出读取服务端已保存的配置，下载 `codex2api-settings-时间.json`；不包含浏览器尚未保存的草稿。

文件格式为 `format=codex2api.settings`、`version=1`，通用字段位于 `settings`，独立配置位于 `sections`：Claude 全局配置、Antigravity 模型重定向、渠道测连参数、邀请引导和可见渠道。普通主设置使用管理员鉴权的 `GET /api/admin/settings/export` 提供，浏览器再合并独立配置端点；接口响应禁止缓存。

文件包含系统代理、图像存储等配置，以及相应服务密钥、GitHub Token、审核 API Key，应作为私密配置文件保存。导入保留目标服务器的管理员登录密钥。账号凭据、API 访问密钥记录、日志、数据库/缓存连接信息、环境变量、动态运行状态以及独立规则页的自定义 Prompt 规则不属于此次迁移范围。本地背景图等文件只迁移路径配置，文件本身需另外复制；含服务器本地引用的规则或路径迁移后应核对目标环境。

选择 JSON 文件后先验证格式、版本、目标服务器支持的字段和字段类型，最大 10 MiB。显示通用字段数量和独立配置范围，点击“导入并覆盖”后按各自现有设置端点进行保存，沿用对应校验和热更新。文件中明确的 `false`、`0`、空字符串和空列表保持原意；未提供的通用字段保留目标值。只读字段与管理员登录密钥不允许通过此导入界面覆盖。

各配置分区依次提交，跨分区并非一个数据库事务。若某一区域校验或保存失败，立即停止后续区域，并显示失败原因及此前已成功应用的区域，不会显示整体成功。完成或出现部分成功后刷新页面，确保主设置与独立卡片显示服务端当前状态。

`sever` 保留旧字段 `codex_initial_session_age_check_disabled` 和 `codex_initial_session_max_age_seconds` 的导入导出兼容性，但已移除首次会话 ID 格式和时间差准入校验。无论导入何值，都不会重新开启检查；首次绑定时的旧 Turn-State 清理和独立的会话序号模式仍保留。详见 [首次主会话处理](initial-session-admission.md)。
