# 跨会话用户冷却

“Prompt 检查”的简化设置与专家设置均支持 `user_cyber_cooldown_minutes` 为 0—1440，缺省保持 30 分钟。

设为 0 后，立即停止按已验证用户的历史 CYB/BIO 记录拦截其他会话；已有冷却记录不会删除，但不再作为活动用户冷却展示或优先排序。无会话标识的新事件不创建仅用于用户冷却的锁。共用此时长的匿名请求精确指纹重放冷却也停止，不会把 0 解释为永久锁。

会话锁由 `conversation_lock_enabled` 和独立的会话锁时长控制。关闭跨会话冷却不改变当前会话锁、事件审计或处罚开关。重新设为正数后，仍在新时长范围内的历史记录可重新参与冷却计算。

配置保存、导出和重新读取均保留明确的 0；未提供字段的旧配置继续使用 30 分钟默认值。负值回退为默认值，超出 1440 的值按上限归一化。
