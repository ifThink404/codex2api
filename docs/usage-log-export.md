# 使用日志下载

「使用统计 → 请求日志」提供两个下载按钮，点击后先弹出确认框，确认后才请求文件：

- **按筛选下载**：沿用点击时的时间范围和全部列表筛选（含搜索、渠道、状态、客户端 UA 等），导出全部匹配记录，不受当前页码和每页条数限制。
- **全部下载**：忽略时间和筛选，导出仍保留的全部使用日志（含失败、取消和内部请求）。

接口：`POST /api/admin/usage/logs/export?scope=filtered|all&confirmed=true`，`filtered` 需要成对的 RFC3339 `start/end`，其余参数与 `GET /api/admin/usage/logs` 相同。

- 每条记录与日志列表接口返回的字段一致；字符串中疑似凭据（Bearer、`sk-`、`*_token=`、`api_key=` 等）再次脱敏，凭据类字段名直接删除。
- 最多导出最新 200,000 条；超出时文件尾部 `complete` 为 `false`。
- 服务端先按行流式写入临时文件再返回，内存占用不随行数增长；同一时间只允许一个导出，重复请求返回 409；单次导出最长 10 分钟，客户端取消后不会返回半截文件。
